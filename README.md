# TheVault: open-source components and their sources

TheVault's ISO is built on open-source software. Each part stays under its own licence.
This repository holds, for every version of TheVault that is handed out, the licence of each part
and its complete corresponding source. It holds no code of TheVault's own.

- One folder per part, as the box lists it (Settings, License, Third-party notices): `LICENSE` and `README.md`.
- The sources are files on the release named after the version (the box links to its own version's tag).
- `installer/`: the installer's and the ISO's package pool's parts.

This tree is 1.0.2-db670de: 732 parts, 427 source bundles.
